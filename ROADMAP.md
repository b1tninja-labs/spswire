# spswire

The reader is code and is pinned by a named test. A row stays `[ ]` until that code exists, and a
test marked `(to be written)` must not exist yet. Nothing here calls firmware trusted, and no GM
firmware bytes are vendored: every test buffer is built from the documented layout. A format whose
record widths are not pinned stays a `[ ]` row until a sample fixes them.

## Session

The `0x4d` LZ77 codec, the U-Boot legacy header, the i.MX6 IVT, the `.smd` bundle and the `.mnf`
release XML are code, as is the end-to-end `uImage` → kernel capability and the `container.iso`
member map (which delegates the ISO 9660 walk to an injected reader, keeping no dependency here).
The binary `.mnf` index and the V850 `master.dnl` `$FLW_WRITER` framing wait for a sample.

| Obligation | Spec | Status | Where | Milestone |
|---|---|---|---|---|
| `spswire.lz77` | GM `comp=0x4d` uImage LZ77 codec | `[ok]` | Decode a GM `comp=0x4d` buffer: the 8-byte `[out_size][comp_size]` header and the 3-byte `literal \| length \| distance` tokens, with overlap-capable back-references and the 8 MiB output cap. A short buffer, a `comp_size` more than ten bytes off the body, an out-of-range back-reference and an oversized `out_size` are errors. Test: `tests/test_lz77.py::test_a_literal_only_stream_round_trips`, `tests/test_lz77.py::test_a_back_reference_copies_with_overlap`, `tests/test_lz77.py::test_comp_size_too_far_from_the_body_is_an_error`, `tests/test_lz77.py::test_an_out_of_range_back_reference_is_an_error` | - |
| `spswire.uimage` | U-Boot legacy `image_header_t` | `[ok]` | Parse the 64-byte big-endian header (magic `0x27051956`), report load/entry and the compression type, flag the `0x4d` GM codec, and return the payload slice. A bad magic and a payload past the buffer are errors. Test: `tests/test_uimage.py::test_a_gm_lz77_kernel_header_is_parsed`, `tests/test_uimage.py::test_the_payload_slice_follows_the_header`, `tests/test_uimage.py::test_a_bad_magic_is_an_error` | - |
| `spswire.kernel` | `uImage` → kernel (compose `uimage` + `lz77`) | `[ok]` | Decompress a `uImage` to its kernel end to end: parse the 64-byte header, take the payload, and run the `0x4d` LZ77 reader, or return an uncompressed image as-is. Any other compression is an error, and a bad header or stream raises the underlying parser error. Test: `tests/test_kernel.py::test_a_gm_lz77_uimage_decompresses_to_its_payload`, `tests/test_kernel.py::test_an_uncompressed_uimage_is_returned_as_is`, `tests/test_kernel.py::test_an_unsupported_compression_is_an_error` | - |
| `spswire.ivt` | i.MX6 HAB Image Vector Table | `[ok]` | Parse the 32-byte Image Vector Table (tag `0xd1`, length `0x0020`), translate a load-address pointer to a file offset, and report the HAB-open shape — no CSF, or a CSF that resolves to end-of-file. A non-IVT buffer is an error. Test: `tests/test_ivt.py::test_a_bootloader_ivt_is_parsed`, `tests/test_ivt.py::test_a_csf_that_resolves_to_eof_is_hab_open`, `tests/test_ivt.py::test_a_csf_inside_the_image_is_not_hab_open` | - |
| `spswire.smd` | GM `.smd` PEM signature bundle | `[ok]` | Split a GM `.smd` PEM bundle (not PKCS#7) into the signer certificate, the manifest digest and signature, and the per-PN digest/signature rows. An input with no `-----BEGIN-----` block is an error. The reader does not evaluate the signatures. Test: `tests/test_smd.py::test_the_certificate_and_manifest_rows_are_recovered`, `tests/test_smd.py::test_each_part_pairs_its_digest_and_signature` | - |
| `spswire.mnf` | GM `.mnf` manifest (base64 release XML) | `[part]` | Recover the base64 release XML a `.mnf` carries: the longest base64 run whose decode is an XML document. A file with no such run is an error. The binary PN→(size,SHA-256) index is the open row below. Test: `tests/test_mnf.py::test_the_release_xml_is_decoded_from_the_blob`, `tests/test_mnf.py::test_a_file_with_no_xml_blob_is_an_error` | - |
| `spswire.mnf.index` | GM `.mnf` binary part-number index | `[ ]` | Parse the binary part-number → (size, SHA-256) index at the head of a `.mnf`, with the `.smd` row zeroed. The record widths are not pinned and need a sample `.mnf`; none is vendored. Test: `tests/test_mnf_index.py::test_the_part_number_index_is_parsed` (to be written) | - |
| `spswire.container` | `container.iso` (ISO/IEC 9660) | `[ok]` | Map the known container paths (`security/cacert.pem`, `public_codekey.pem`, `firmware/v850/*/master.dnl` and the `*.crc` sidecars) to their bytes by delegating the walk to any injected reader exposing `member(path)` (for example `iso9660.Volume`) — no ISO parser and no dependency on one is kept here. An unknown V850 variant or CRC section is rejected before a read. Test: `tests/test_container.py::test_a_known_container_path_returns_its_bytes`, `tests/test_container.py::test_an_unknown_variant_or_section_is_rejected_before_a_read` | - |
| `spswire.dnl` | V850 `master.dnl` `$FLW_WRITER` framing | `[ ]` | Parse the Renesas `$FLW_WRITER` download stream of `master.dnl` — the `8X nn` record headers, the little-endian target addresses, the `0x55` fill and the CRC16 trailers — into a byte-exact section map. Needs a sample to fix the record semantics. Test: `tests/test_dnl.py::test_the_flw_writer_records_are_framed` (to be written) | - |
